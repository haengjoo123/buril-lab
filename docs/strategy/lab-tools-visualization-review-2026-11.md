# 실험 도구 시각화 검토 (2026-11-27)

실험 도구 25개(기존 23개 + 새 도구 2개)의 화면 기능을 하나씩 살펴, 그림으로 보여 줄 때 사용자가 결과를 더 빨리, 더 정확하게 이해하는 항목을 골랐다. "보기 좋다"가 아니라 **실험대에서 판단이나 실수를 줄이는가**를 기준으로 했다.

## 판단 기준

| 기준 | 질문 |
|---|---|
| 판단에 쓰이는가 | 그림을 보고 무엇을 결정하거나 확인하는가? (피펫으로 뜰 수 있는 양인지, 표준 범위 안인지, 끝났는지) |
| 숫자보다 빠른가 | 표나 숫자 하나로 충분하면 그림은 넣지 않는다 |
| 형태가 맞는가 | 자료의 성격이 형태를 정한다: 전체 중 일부 → 분할 막대, 한도 대비 비율 → 미터, 크기 비교 → 막대, 변화 → 선, 격자 위의 크기 → 한 색상 농담 |
| 잘못 읽힐 위험 | 모델 예측을 실측처럼 보이게 하지 않는가, 축을 둘 쓰지 않는가 |

숫자 하나가 결과인 도구(몰농도, 단위 변환, 계산기)는 숫자 자체가 답이므로 그림을 넣지 않는다.

| 희석(연속) | 단계별 표 | 어느 관에서 어느 관으로 얼마를 옮기는가 | 관 도식(이송량·농도 표시) | **적용** |
| 몰농도 | 숫자와 단위별 환산 | — 결과가 숫자 하나 | — | 넣지 않음 |
| 마스터 믹스 | 성분 표 | 반응 한 번이 무엇으로 채워지는가, 빠진 부피는 없는가 | 얇은 분할 막대(성분별 부피) | **적용** |
| 배지/버퍼 | 성분·단계 체크 | 제조가 어디까지 진행됐는가 | 미터(완료한 단계 수) | **적용** |

넣지 않은 것과 이유:

- **도넛·파이**: 전체 중 일부는 분할 막대가 더 정확하게 읽힌다.
- **축이 둘인 그림**: 두 측정값의 눈금 맞춤이 임의라 없는 상관을 만든다. 검량선의 잔차는 본 그림과 별도 그림으로 둔다.
- **알람의 주간 띠, 단위 변환의 곡선**: 목록과 표로 이미 답이 나온다.
- **장식용 일러스트**(비커, 저울 등): 판단에 쓰이지 않는다.

## 공통 규칙

구현은 `src/features/tools/charts.tsx`(+ `chartMath.ts`, `charts.css`)에 모았다. 부품은 분할 막대(`SegmentedBar`), 미터(`Meter`), 막대 목록(`BarList`), 선·점 그림(`Plot`), 농담 눈금(`ScaleLegend`), 옮김 도식(`TransferChain`)이고 모두 `ChartFrame`(제목·설명·범례·"표로 보기") 안에 둔다.

- **형태 다음에 색**. 범주는 고정 순서(파랑, 주황, 청록, 노랑, 자홍, 초록) 6색까지만 쓰고 그 이상은 "기타"로 접는다. 크기는 한 색상의 농담, 양·음은 파랑↔빨강과 중립 기준선.
- **색은 검증했다**. 앱의 실제 배경(밝은 `#ffffff`, 어두운 `#172238`)에서 색각 이상 구분(인접 ΔE ≥ 8)과 일반 시야 구분(≥ 15)을 통과했다. 밝은 배경에서 청록·노랑·자홍은 배경 대비가 3:1에 못 미치므로 모든 그림에 **값 라벨과 "표로 보기"**를 함께 둔다.
- **글자는 계열 색을 쓰지 않는다**. 이름과 값은 본문 색, 색은 옆의 표식이 맡는다. 채움 안의 글자만 흰색(노랑 위는 검정).
- **가는 표식**: 선 2px, 점 8px 이상에 배경색 테두리 2px, 막대는 기준선 쪽 직각·끝쪽 둥글게, 격자는 실선 1px.
- **값은 그림 없이도 읽힌다**: 모든 그림에 표가 딸리고, 가리키거나 키보드로 초점을 주면 값을 보여 준다.
- **예측은 예측으로 표시**: 세포 성장 곡선은 "모델 예상"임을 제목 옆에 적는다.
- **어두운 화면**은 자동 반전이 아니라 따로 고른 단계를 쓴다(크기 농담은 어두운 배경에서 밝을수록 큰 값).
- **로그 축은 둥근 값에 눈금**을 둔다(100·200·500·1000). 로그값을 균등하게 나눈 158·251 같은 눈금은 쓰지 않는다(`logTicks`).
- **좁은 화면**(480px 이하)에서 막대 목록은 이름과 값 한 줄, 그 아래 막대 한 줄로 바뀐다.

## 적용 결과 (2026-11-27)

위 표에서 **적용**으로 정한 17개 도구 18개 항목을 모두 구현했다. 넣지 않기로 한 8개 도구(몰농도, 알람, 계산기, 단위 변환, 노트, 캘린더, 코돈, 래더)는 표에 적은 이유대로 그대로 두었다.

| 도구 | 구현한 그림 | 위치 |
|---|---|---|
| 희석 | 최종 부피 구성 막대, 연속 희석 옮김 도식(12단계까지) | `DilutionTool.tsx` |
| 마스터 믹스 · 배지/버퍼 | 반응 한 번의 구성 막대(성분 7개 초과면 막대 목록), 제조 진행 미터 | `MixTool.tsx` |
| 플레이트 라벨링 | 농도 보기(농담 + 눈금) | `PlateTool.tsx`, `plate.ts` |
| 젤/블롯 | 이동 거리–크기(log) 그림, 래더와 추정 밴드 | `imageParts.tsx`, `gel.ts` |
| 이미지 측정 | 측정값 막대 목록과 통계 | `imageParts.tsx` |
| 세포 배양 | 성장 곡선(목표선, 현재·도달 시점, "모델 예상") | `CultureTool.tsx` |
| 세포 계수 | 생존/사멸 분할 막대, 구획별 막대 목록(평균·변동계수) | `CellCounterTool.tsx` |

화면 확인은 로그인 없이 뜨는 미리보기(`adaptive-fixture`)에서 했다. 실제 값으로 계산이 맞는지 본 것: 희석 연속 계열, 마스터 믹스 구성, 수식 곡선과 현재값, 젤 밴드 추정(≈ 223 bp, 손계산 일치), 세포 계수(2.16 × 10⁶ cells/mL)와 성장 예상(34 h), 이미지 측정 통계.
