## 훈련 중 발견해 고친 문제

1. 복구된 사진 본문은 대상 Storage에 있었지만 DB의 `image_url`이 운영 주소를 가리키고 있었습니다. 임시 대상 DB의 1행을 대상 주소로 바꾼 뒤 운영 참조 0건과 해시 일치를 재검증했습니다. 운영 DB는 수정하지 않았습니다.
2. 오래된 `?record=` 링크가 현재 30일 목록 밖의 ID를 직접 조회하지 않았고 묶음도 자동으로 열지 않았습니다. 현재 연구실 범위를 유지하는 ID 직접 조회와 묶음 자동 열기를 추가하고 단위시험과 실제 브라우저 재검증을 통과했습니다.
3. Windows 자식 프로세스 환경 전달이 실패한 첫 빌드는 대상·운영 식별자가 모두 0개인 빈 설정 빌드로 판정해 폐기했습니다. 비밀값을 파일이나 인자에 쓰지 않고 자식 환경으로만 전달해 다시 빌드했고, 대상 식별자 1개·운영 식별자 0개를 확인했습니다.
